# In-class exercises — Image Processing Fundamentals

**Six exercises, separate from the take-home rice mini project.** Uses MATLAB sample images `cameraman.tif`, `pout.tif`, and `coins.png`; do not upload those source images.

## Files and reproduction

- `exercises.m`: complete MATLAB source, six sections and automatic figures/tables.
- `THINK_ABOUT_ANSWERS.md`: short draft conceptual answers; check specific visual conclusions against actual output.
- `results/`: created automatically by the MATLAB script when run.
- `exercises.mlx` and `exercises.pdf`: **must be generated by MATLAB Live Editor after execution; not included in this unexecuted source package.**

### Run in MATLAB Online

1. Make `exercises/` the MATLAB Current Folder.
2. Open `exercises.m`; use **Save As → Live Script**, saving as `exercises.mlx` (do not just rename its extension).
3. Run the entire Live Script with the Image Processing Toolbox installed. It saves PNGs and CSVs in `results/`.
4. Verify every plotted comparison and numeric table. Add one or two sentences for each Think about prompt to the Live Script, drawing on `THINK_ABOUT_ANSWERS.md` and your actual figures.
5. Save `exercises.mlx` **with output**, then **Export → PDF** to `exercises.pdf`. Inspect the PDF to confirm it contains all six exercises and the measured results.
6. Commit the `exercises/` folder into your existing `Digital-Signal-Processing` repository as an ordinary folder (no nested `.git` directory).
